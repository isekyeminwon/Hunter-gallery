# 대한민국 헌터 갤러리

> **2042년의 익명 헌터 커뮤니티를 실제로 열람하는 듯한 경험을 만드는 정적 웹 프로젝트**

`대한민국 헌터 갤러리`(이하 **헌갤**)는 가상의 헌터 사회가 20년 동안 축적해 온 게시글, 댓글, 사건 기록, 밈, 공략, 구인글을 하나의 커뮤니티 아카이브처럼 보여주는 React 기반 웹 프로젝트입니다.

단순한 설정집이나 위키가 아니라, 사용자가 직접 오래된 글을 검색하고 댓글 흐름을 읽으며 세계관을 발견하도록 설계했습니다.

---

## 프로젝트 한눈에 보기

- **형태:** 한국식 익명 갤러리형 커뮤니티
- **현재 시점:** 2042년 9월 17일
- **아카이브 범위:** 2022년 ~ 2042년
- **목표 게시글:** 1,200개
- **프런트엔드:** React + Vite + TypeScript
- **배포:** Cloudflare Pages
- **지원 화면:** PC / 태블릿 / 모바일 반응형

헌갤은 2042년 기준 대한민국 최대 규모의 헌터 전문 익명 커뮤니티라는 설정입니다. 현역 헌터, 짐꾼, 길드 관계자, 일반인, 방송 시청자, 업계 종사자 등이 뒤섞여 사용하는 공간을 지향합니다.

---

## 이 프로젝트에서 할 수 있는 것

### 게시글 읽기

20년치 게시글을 연도순으로 탐색할 수 있습니다.

- 일상 잡담
- 질문 / 뉴비글
- 공략 / 현장 후기
- 사건 / 속보
- 갈드컵 / 랭킹
- 방송 / 팬덤
- 구인 / 시장
- 협회 / 법 / 범죄

같은 유형의 글이 한 커뮤니티 안에서 자연스럽게 섞입니다.

### 댓글과 대댓글 보기

댓글은 단순 장식이 아니라 세계관 전달의 핵심 요소입니다.

- 익명 댓글
- 고정닉 / 직업닉
- 대댓글 싸움
- 성지순례
- 삭제댓글
- 시대별 밈
- 헌갤콘

주요 사건글이나 개념글은 댓글과 답글이 활발하게 이어지도록 구성합니다.

### 검색과 아카이브 탐색

검색 범위:

- 제목
- 제목 + 본문
- 작성자
- 댓글

필터:

- 연도
- 말머리
- 최신순
- 오래된순
- 인기순

또한 `개념글`, `공지`, `고전글` 탭을 통해 특정 성격의 글만 따로 볼 수 있습니다.

---

## 읽기는 되지만, 쓰기는 되지 않습니다

헌갤의 핵심 연출 중 하나입니다.

사용자는 사이트를 정상적으로 읽고 검색하고 탐색할 수 있지만 아래 행동은 항상 실패합니다.

- 글쓰기
- 댓글 등록
- 추천
- 신고
- 로그인
- 회원가입

버튼 자체는 눌리지만, 현재 접속 환경이 정상적인 서비스 영역이 아니라는 식의 오류가 표시됩니다.

즉 사용자는 **살아 있는 커뮤니티를 다른 곳에서 관측하고 있지만 직접 개입할 수는 없는 상태**를 경험하게 됩니다.

---

## 왜 위키가 아니라 커뮤니티인가?

이 프로젝트의 목표는 설정을 설명하는 것이 아니라 **사람들이 그 세계에서 실제로 살았던 흔적을 보여주는 것**입니다.

예를 들어 같은 사건도 다음과 같이 여러 각도에서 보입니다.

```text
[사건] 강원 저등급 게이트 실종 또 떴네

[질문] 저쪽 요즘 공략 가도 됨?

[일반] 또 카더라 시작이네

[정보] 협회 공지 정리함

[고전글] 8년 전에도 비슷한 글 있었네
```

공식 설명 하나보다 서로 다른 이용자들의 반응, 오해, 농담, 갈등이 겹치면서 세계관이 드러나는 방식을 지향합니다.

---

## 20년치 아카이브

아카이브는 2022년 첫 게이트 시기부터 2042년 현재까지 이어집니다.

초기 자료는 커뮤니티가 아직 자리 잡기 전의 외부 기록이나 캡처본처럼 보일 수 있습니다.

```text
외부기록
캡처본
재업
```

시간이 흐를수록 용어와 제도가 정착되고, 게시판 분위기 또한 달라집니다.

- 초기 게이트 목격담
- 각성자의 등장
- 헌터 제도 형성
- 협회와 면허
- 길드 산업 성장
- 마석 시장
- 방송과 팬덤
- 대형 사건과 실종
- 2042년 현재의 일상

이 변화가 게시글 제목, 말투, 조회수, 댓글 문화에 자연스럽게 반영되도록 제작합니다.

---

## 개념글과 고전글

### 개념글

추천수와 댓글 반응을 기반으로 커뮤니티에서 크게 주목받은 글입니다.

내부 인기 점수는 다음 요소를 함께 반영합니다.

```text
추천 × 2 + 댓글 수
```

### 고전글

오래된 사건, 성지, 밈, 역사적으로 의미가 남은 글을 모아두는 영역입니다.

고전글에는 수년 뒤 이용자가 찾아와 남긴 `성지순례` 댓글이 섞일 수도 있습니다.

---

## 헌갤콘

댓글과 본문에는 자체 이모티콘 시스템인 **헌갤콘**을 사용할 수 있습니다.

데이터에서는 다음 형태로 저장합니다.

```text
{{con:hello}}
{{con:heehee}}
{{con:dororong}}
```

렌더링 시 실제 이미지로 표시됩니다.

현재 별하나콘은 2035년 이후 댓글에서 사용할 수 있으며, 오래된 글에 나중에 달린 성지순례 댓글에서도 정상적으로 사용할 수 있습니다.

---

## 광고

사이트 프레임의 광고는 항상 **2042년 현재 광고**로 표시됩니다.

지원 슬롯:

```text
header-banner
right-sidebar
post-inline
```

헌터 장비, 보험, 마석 관련 서비스뿐 아니라 통신사, 자동차, 배달, 게임 등 일반 소비재 광고도 함께 섞입니다.

광고 이미지는 데이터만 추가하면 교체할 수 있습니다.

---

## 반응형 지원

별도의 모바일 사이트를 만들지 않습니다.

하나의 React 코드베이스에서 CSS 반응형으로 대응합니다.

- **PC:** 고밀도 게시판 + 우측 사이드바
- **태블릿:** 본문 중심 단일 컬럼 전환
- **모바일:** 제목 중심 목록 + 메타정보 재배치

게시글 상세화면은 PC에서 더 넓게 표시되고, 모바일에서는 화면 폭에 맞게 자동으로 축소됩니다.

## 데이터 구조

사람이 직접 관리하는 원본은 하나입니다.

```text
source/hunter-gallery-master.json
```

이 파일 안에 현재 공지와 전체 게시글, 댓글이 모두 들어갑니다.

```json
{
  "version": "1.1",
  "snapshot": "2042-09-17",
  "notices": [],
  "posts": []
}
```

빌드 단계에서 자동으로 다음 파일들로 분리됩니다.

```text
public/generated/
├─ post-index.json
├─ search-index.json
├─ concept-index.json
├─ trending-index.json
├─ notices.json
├─ years/
└─ posts/
```

React 앱은 이 생성 결과를 읽습니다.

## 데이터 검증

대량의 게시글을 다루기 때문에 validator를 함께 사용합니다.

자동으로 검사하는 항목 예시:

- 게시글 / 댓글 ID 중복
- 잘못된 대댓글 parentId
- 댓글 시간 역전
- 삭제 데이터 노출
- 존재하지 않는 헌갤콘
- 헌갤콘 등장 연도
- 게시글 연도별 수량
- 카테고리별 수량
- 개념글 / 고전글 수량
- 삭제·유실 자료 수량
- 세계관상 공개되면 안 되는 정보 패턴

최종 1,200개 데이터셋에서는 편성표까지 exact count로 검증합니다.

## 로컬 실행

```bash
npm install
npm run dev
```

데이터만 수정했다면:

```bash
npm run data:prepare
```

을 실행하면 원본 JSON 검증과 `public/generated` 재생성이 함께 진행됩니다.

프로덕션 빌드:

```bash
npm run build
```

---

## Cloudflare Pages 배포

```text
Build command: npm run build
Build output directory: dist
Production branch: main
```

SPA fallback은 `public/_redirects`에 포함되어 있습니다.

```text
/* /index.html 200
```

## 프로젝트 상태

현재는 **기능 구현과 데이터 파이프라인을 안정화한 뒤, 20년치 본 아카이브 콘텐츠를 제작하는 단계**입니다.

최종 목표는 단순히 게시글 1,200개를 채우는 것이 아니라, 사용자가 검색하다가 우연히 오래된 사건글을 발견하고 댓글을 타고 들어가면서 실제 커뮤니티를 탐색하는 듯한 경험을 만드는 것입니다.

## 제작 방향

이 프로젝트는 특정 실제 커뮤니티를 그대로 복제하는 것을 목표로 하지 않습니다.

한국식 익명 게시판의 익숙한 구조를 참고하되, 자체 로고, 색상, 탭, 광고, 세계관, 이용안내, 데이터 구조를 사용하는 독립적인 가상 커뮤니티를 지향합니다.
